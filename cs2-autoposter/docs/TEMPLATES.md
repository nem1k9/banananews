# Шаблоны без Photoshop

`templates/default.json` описывает размеры, фон, панели, акцент, foreground, шрифт и размеры заголовков. В `categories` пять отдельных стилей TRANSFER / MATCH_RESULT / ROSTER / UPDATE / GENERAL_NEWS. Шрифт Noto Sans с кириллицей включён в bundle, лицензия — assets/OFL.txt. SVG-компоновщик делает переносы и масштабирование, resvg WASM — PNG. Ни браузер, ни системные нативные модули в Worker не нужны.

Экспортируйте из PSD статичный фон и слои PNG. Сохраните их в assets и преобразуйте в data URI в JSON (например `data:image/png;base64,...`). Поле backgroundLayer — фон; Card.photo — фото; Card.logos — массив логотипов. Внешние URL не рекомендуются: медленная загрузка и произвольные ресурсы недопустимы в срочном пути. Предварительно проверяйте права на фотографии. PNG должен быть небольшим; не храните многомегабайтные слои в D1.

title ограничен 240 символами, автоматически переносится и уменьшается до minTitleSize. Результат серии использует отдельное поле score. subtitle — турнир. Размер по умолчанию 1080×1080. После изменения размеров обязательно проверьте карточки с длинными русскими заголовками визуально: подгонка не гарантирует идеальную композицию любого PSD.

Чтобы заменить демонстрационный стиль, измените JSON и разверните Worker. Не нужно менять сохранённые публикации. Панель позволяет выбрать акцент категории или общий фирменный фиолетовый; новые карточки сохраняют выбранный вариант. Панель сообщает активный шаблон; произвольная загрузка PSD через админку не реализована и не выдаётся за поддержку PSD-парсинга.
