# Проверки в текущей среде

Проверка 17 ноября 2026. Локальные проверки не означают публикацию Cloudflare deployment.

- TypeScript: `npm run typecheck`.
- Интеграционные тесты workerd: 22 сценария, настоящие локальные D1 и Durable Objects, PNG через resvg WASM. Внешние Telegram/Steam вызовы в тестах — явные HTTP-фикстуры, не настоящие отправки.
- Локальная миграция D1 выполнена.
- Wrangler dry-run собирает Worker и статические файлы; это не remote deploy.
- Локальная симуляция NAVI vs Vitality 2:1 создала один dry-run пост; повтор события не увеличил количество. В первом измерении processing_ms=257, detection_ms=1 (mock). Эти цифры не относятся к боевому провайдеру или Telegram.
- PNG открыт и проверен визуально: кириллица, счёт, турнир, 1080×1080.
- Headless Chromium: вход в панель, история, загрузка PNG, ноль pageerror. Снимки лежат в игнорируемой папке artifacts.
- Официальный Steam endpoint из shell вернул HTTP 200, appid=730 и steam_community_announcements. В локальном workerd этой управляемой среды исходящий запрос заканчивается `Network connection lost`; source становится error, остальная система работает. Доступ по сети из опубликованного Cloudflare Worker пока не проверен. Не отключайте TLS и не заменяйте ошибки фиктивными новостями.
- Команды установленного Codex CLI `exec --help` / `login --help` проверены, официальная документация авторизации прочитана. Авторизация владельца и настоящая генерация Codex на отдельном VPS НЕ проверены. Вложенный агент для обхода этого условия не запускался.
- Нет CLOUDFLARE_API_TOKEN / CLOUDFLARE_ACCOUNT_ID и TELEGRAM_TEST_CHANNEL_ID. Реальный деплой, тестовая Telegram отправка, live-API latency и круглосуточная работа на VPS НЕ проверены. Токен старого проекта не использовался.

Тесты используют explicit очистку локальной DB между сценариями и `isolatedStorage=false`: версия тестового пула имеет проблему snapshot SQLite Durable Objects с файлами -shm. Состояние очищается перед каждым тестом, DO имеют уникальные ID сценариев; конкурентные вызовы тестируются отдельно, а не отключаются.
